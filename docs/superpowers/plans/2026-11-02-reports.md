# ระบบรายงาน (ตารางข้อมูล) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** เพิ่มเมนู "รายงาน" ให้ ADMIN และ MANAGER ดูคำขอ ผู้ใช้ และสถิติสรุปเป็นตารางที่ค้นหา กรอง เรียงได้ พร้อมปุ่มเพิ่ม/แก้ไข/ลบ (แก้ไขใน popup)

**Architecture:** ตารางฝั่งเซิร์ฟเวอร์ (`DataTable`) ที่เก็บค้นหา/กรอง/เรียง/หน้า/popup ไว้ใน URL; กติกาที่ไม่แตะ DB (อ่านพารามิเตอร์, ขอบเขตสิทธิ์, ตัวสร้าง `where`, สรุปสถิติ, `safeReturn`) อยู่ใน pure module ที่เทสต์ด้วย vitest; query อยู่ใน `report-queries.ts` (server-only) และบังคับขอบเขตของหัวหน้างานเอง; popup เป็น `<dialog>` ที่เปิดจาก `?edit=`/`?new=1`; ปุ่มท้ายแถวเรียก server action เดิม

**Tech Stack:** Next.js 16.4.3 App Router (server components, server actions, `useActionState`), TypeScript, Tailwind 4, Prisma 6.19.3, PostgreSQL, zod 4, vitest, lucide-react

**Spec:** `docs/superpowers/specs/2026-11-02-reports-design.md` (อ่านก่อนเริ่ม ข้อ 4.x ในแผนนี้อ้างถึง spec)
